# Bastiao Autodidata

Agente autonomo que se auto-desenvolve lendo issues do GitHub.

## Como Funciona

1. Lê issues do GitHub
2. Planeja implementacao
3. Escreve codigo
4. Testa
5. Comita
6. Repete

## Uso

```bash
export GITHUB_TOKEN=seu_token
python main.py
```
